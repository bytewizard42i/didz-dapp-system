# Pruning and Archival Protocol

This repository does not define an independent pruning and archival protocol.

The sole source of truth is the [DIDzM Pruning and Archival Protocol](../../DIDzMonolith-docs/standards/DIDZM_PRUNING_AND_ARCHIVAL_PROTOCOL.md).

## DIDz responsibility

DIDz supplies minimal identity lifecycle facts, controller authority, key rotation, trusted attestations, and references to archive commitments where the root protocol requires them.

DIDz does not operate archival storage, prove biological life, decide retention policy, or redefine the root protocol. Identity status, controller rotation, correction, supersession, and archive availability remain separate concepts.
