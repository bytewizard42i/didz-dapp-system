# DIDz MidnightVitals Profile

The canonical protocol is maintained at
[`../../DIDzMonolith-docs/standards/MIDNIGHTVITALS_PROTOCOL.md`](../../DIDzMonolith-docs/standards/MIDNIGHTVITALS_PROTOCOL.md).

DIDz is the first semantic conformance pilot. Its local profile should verify
registry health, credential status, issuer trust, selective presentation, key
rotation, and recovery-policy behavior without exposing subject data. This file
is a pointer and profile boundary, not a competing protocol specification.
